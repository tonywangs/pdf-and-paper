    Supported files & recovery

    Import a folder containing only UTF-8 .md chapters and PNG, JPEG or GIF assets. Headings, paragraphs, emphasis, lists, quotes, fenced code, images and links are supported. Use relative chapter links such as chapter-2.md#heading; explicit heading IDs use # Heading {#my-id}. Duplicate generated headings get -2, -3 suffixes. Raw HTML, tables, footnotes, templates and other extensions are rejected or flagged; see README for the precise subset.

    The browser saves your source snapshot, metadata and order in IndexedDB after successful validation. Save a project file for portable recovery; clearing browser data removes local recovery. Files on disk are never modified or monitored. Verify their folder to detect missing, added or changed files. To adopt edits, import a new source folder. Limits: 200 files, 8 MiB each, 20 MiB total. First launch needs Node.js 20+ and npm access; subsequent use is local.
