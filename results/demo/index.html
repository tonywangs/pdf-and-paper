PDF redaction check — public PDF demo

Controlled examples, not evidence of a vulnerability in the original publication. No detected text does not certify secure redaction.

This offline experiment uses a real, openly licensed publisher PDF. It compares visual masking with applied redaction using PyMuPDF region evidence and independent pypdf page extraction.

Changes: The packaged source is unmodified. Demo variants extract PDF page 1 (the title page) and deliberately mask, annotate, rotate or apply redaction to the subtitle, or add a decorative rectangle. These are controlled examples, not discovered vulnerabilities in the original publication.
