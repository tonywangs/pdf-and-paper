    A record, not just a spreadsheet
    Exports include exact UTF-8 CSV strings and a separate manifest with source hash, region, settings, cell links, and full edit history. Deleted values remain in history; undo restores them.
    Review is a human decision
    No OCR or accuracy score. Scans, encrypted files, rotated pages, merged cells, and automatic multipage stitching are unsupported. Multiline cells need explicit row separators.
    Your files stay here
    PDFs stay in this local app’s data directory. Reviews autosave in this browser. Save a project file for backup or transfer; reconnecting requires the same PDF hash. Spreadsheet imports should treat all columns as text.
